# referral-novi

Private Empfehlungsseiten von Eigentümern für ihre Freunde – erzeugt mit dem Generator aus [novi-vinodolski](https://github.com/stephanbohr-stbc/novi-vinodolski).

- Startseite: https://referral-novi.eu/
- Jede Seite liegt unter `seiten/<name>/` und ist unter `https://referral-novi.eu/<name>/` erreichbar (Weiterleitung aus `seiten/` folgt mit der Pipeline).
- Veröffentlichung über GitHub Pages aus dem Branch `main`; `CNAME` bindet die Domain.

Pflege und Ablauf: siehe `docs/konzept-selbstbedienung.md` im Repo `novi-vinodolski`.
